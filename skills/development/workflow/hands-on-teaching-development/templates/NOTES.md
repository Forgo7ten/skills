# Teaching Notes (NOTES.md)

> 本文件由 Agent 直接编辑，记录**经用户确认的长期有效约定**；格式可按项目需要自由组织（如按全局/模块分组、清单或表格）。
> 不记录逐步骤 Review 过程、Agent 未确认的建议或短期学习反馈（分别归入 `development-log.md`、`teaching-state.md`）。

## 记录范围

- **产品需求**：功能边界、行为要求、验收口径等已确认需求。
- **工程与教学偏好**：代码风格、抽象克制程度、依赖倾向、长期教学方式偏好。
- **架构决策**：多方案对比后用户确认的取舍及其理由。
- **纠偏记录**：用户明确推翻或修正旧方案时，更新现行规则并保留简短变更说明。

## 维护原则

- **区分生效与废止**：新约定与旧约定冲突时，明确把旧条目移至「已废止 / 历史变更」或标明替代关系，避免新旧规则同时生效。
- **不把一次性决定写成长期规则**：单次 Review 选择 `user` 或 `agent` 不自动成为长期偏好；只有用户明确提出可复用约束时才写入本文件。
- **可按模块归类**：区分全局适用与仅限特定模块的约束，便于跨会话快速查阅。
- **随提交落盘**：修改本文件后，随最近一次 Agent Project `checkpoint.ts` 一起提交。
