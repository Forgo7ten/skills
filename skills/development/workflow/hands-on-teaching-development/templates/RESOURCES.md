## 使用规则

- 优先使用稳定的相对路径、符号名称及 Git Commit；来源不是 Git 仓库时记录版本或日期，不猜测 SHA。
- 发现示例项目间的冲突，先比较正确性、复杂度、适用场景，再咨询用户。
- 技术选择写入 `development-plan.md`；用户确认的长期取舍写入 `NOTES.md`，本文件仅索引依据。
- 只登记确实有参考价值的资料；不要把示例项目整个文件树抄进来。
